# Clasificaci-n-Gatos-y-Perros
## Descripción
Este proyecto implementa un clasificador de imágenes para distinguir entre gatos y perros utilizando redes neuronales profundas.

## Características
- Carga y preprocesamiento de imágenes
- Entrenamiento de modelo de clasificación
- Evaluación de resultados
- Visualización de predicciones

## Uso
Ejecutar el notebook para entrenar el modelo y realizar clasificaciones en nuevas imagenes
